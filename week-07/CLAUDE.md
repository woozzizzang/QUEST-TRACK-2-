# week-07 · 로그인하면 열리는 내 사이트

## 주제
- 로그인하면 열리는 내 사이트

## 이번 주 목표
- 내 작품을 먼저 만들고, 마지막에 로그인과 보관함을 붙이기

## 이번 주 규칙
- 로그인과 보관함은 아직 만들지 않고, 로그인 단추 자리만 비워 둔다.
- 기록은 지금은 이 기기의 브라우저에 저장하고, 저장하는 코드는 한곳에 모아 둔다.
- 답은 한국어로 한다.

## 내 작품
- 점수를 겨루는 미니 게임과 누구나 보는 온라인 랭킹 (`index.html` · 별 잡기)
- 남길 것: 점수 · 난이도 · 날짜 (처음 부탁에 "남길 것" 칸이 비어 있어서 이렇게 정함)
- 로그인·온라인 보관함이 있어야 하는 기능은 뺐고, 이 기기 랭킹으로 먼저 만든다.

## 기능 표
쉬운 것부터 어려운 것 순서. 넣은 것은 ✅ 로 표시한다.

| 번호 | 기능 | 쓰는 사람에게 좋은 점 | 어려움 | 넣었나 |
|---|---|---|---|---|
| 1 | 미니 게임 한 판(제한 시간 안에 점수 얻기) | 누르면 바로 시작하고, 끝나면 점수가 나와서 한 판이 짧고 분명하다 | ★ | ✅ |
| 2 | 내 최고 점수 저장 | 다시 열어도 내 기록이 남아 있어서 "더 높이" 하고 싶어진다 | ★ | ✅ |
| 3 | 이 기기 랭킹 화면(상위 10개) | 내 기록이 순서대로 보여서 얼마나 늘었는지 알 수 있다 | ★★ | ✅ |
| 4 | 이름(별명) 입력 | 기록에 내 별명이 붙어서 내 기록이라는 느낌이 난다 | ★★ | |
| 5 | 난이도 고르기(쉬움·보통·어려움) | 초보도 고수도 즐기고, 난이도별로 랭킹이 따로 나뉜다 | ★★ | ✅ |
| 6 | 효과음과 끄고 켜는 단추 | 점수를 얻을 때 손맛이 있고, 조용한 곳에서는 끌 수 있다 | ★★★ | |
| 7 | 점수 자랑 카드(그림으로 저장·공유) | 친구에게 내 점수를 보여 주고 싶을 때 바로 보낼 수 있다 | ★★★ | |
| 8 | 폰 화면 터치 조작과 화면 크기 맞추기 | 폰에서도 컴퓨터에서도 불편 없이 할 수 있다 | ★★★★ | ✅ |
