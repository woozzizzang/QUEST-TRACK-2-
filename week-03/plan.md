# week-03 계획서 · 내 캐릭터 데스크톱 펫

## 만들 것
화면 오른쪽 아래 구석에 앉아 있는 하얀 고양이 펫. 내가 키를 누를 때마다 빨간 버튼을 손으로 두드린다.

| 펫 상태 | 보여 줄 그림 (`art/sheet.png` 의 칸) |
|---|---|
| 가만히 있을 때 | ① 왼쪽 위 · 두 손 들기 |
| 키를 누를 때마다 | ② 오른쪽 위 · 오른손 버튼, ③ 왼쪽 아래 · 왼손 버튼을 번갈아 |
| 10초 동안 키를 안 누르면 | ④ 오른쪽 아래 · 졸기 (Zzz) |
| 졸다가 다시 누르면 | 깨어나서 ②③ |

- 크기: 가로세로 약 150픽셀
- 처음 위치: 화면 오른쪽 아래, 작업 표시줄 바로 위
- 마우스: 왼쪽 버튼으로 끌면 옮겨지고, 오른쪽 클릭 메뉴의 "끄기" 로 꺼진다
- 횟수: 펫 머리 위에 "오늘 1,234번" 처럼 오늘 누른 횟수를 작게 표시한다
- 저장: 횟수를 `count.json` 에 날짜와 숫자만 저장한다. 껐다 켜도 오늘 횟수가 이어지고, 날짜가 바뀌면 0부터 다시 센다

## 어디서 돌아가는지
- 내 컴퓨터 (Windows 11) 의 바탕화면 위. 펫 창은 다른 창보다 늘 위에 떠 있다
- 만드는 동안: week-03 전용 가상환경 `.venv` 의 Python 으로 `python pet.py` 를 실행한다
- 다 만든 뒤: PyInstaller 로 묶은 `pet.exe` 를 두 번 클릭해 실행한다 (Python 없이도 돌아감)

## 단계

### 1단계 · 재료 준비
- week-03 에 `.venv` 를 만들고 재료 4가지를 설치한다
- `requirements.txt` 와 `.gitignore` 를 만든다
- **확인할 것**
  - 재료 4가지가 오류 없이 불러와진다
  - Python 3.15 용 PySide6 가 없어서 설치가 안 되면, 멈추고 나한테 물어본다 (다른 Python 버전 설치가 필요할 수 있음)
  - `git status` 에 `.venv` 가 보이지 않는다
- **커밋**: `week-03: 1단계 재료 준비 (requirements, gitignore)`

### 2단계 · 그림 자르기
- `cut.py` 로 `sheet.png` 를 4칸으로 자르고, 각 칸의 빈 가장자리를 잘라 낸 뒤 150픽셀 크기로 줄여 `art/pose1.png` ~ `art/pose4.png` 로 저장한다
- **확인할 것**
  - 4장을 열어 보면 순서가 ① 두 손 ② 오른손 ③ 왼손 ④ 졸기 이다
  - 고양이 귀·꼬리·버튼이 잘리지 않았고, 배경이 투명하다
- **커밋**: `week-03: 2단계 그림 4장 자르기`

### 3단계 · 펫 창 띄우기
- `pet.py` 로 테두리 없는 투명한 창에 ① 을 띄운다. 창은 늘 맨 위에 있고, 작업 표시줄에 버튼이 생기지 않는다
- 처음 위치는 화면 오른쪽 아래, 작업 표시줄 바로 위이다
- **확인할 것**
  - 고양이만 보이고 네모난 배경이 없다
  - 다른 창을 눌러도 펫이 뒤로 숨지 않는다
  - 작업 표시줄에 가려지지 않는다
- **커밋**: `week-03: 3단계 펫 창 띄우기`

### 4단계 · 끌어 옮기기와 끄기
- 왼쪽 버튼으로 끌면 펫이 따라 움직인다
- 오른쪽 클릭 메뉴에 "끄기" 를 넣는다
- **확인할 것**
  - 펫을 화면 여기저기로 옮길 수 있다
  - "끄기" 를 누르면 펫이 사라지고 프로그램도 끝난다 (터미널이 다시 입력을 받음)
- **커밋**: `week-03: 4단계 끌어 옮기기, 오른쪽 클릭 끄기`

### 5단계 · 타자에 맞춰 손 움직이기
- pynput 으로 키가 눌린 것을 알아채고, 누를 때마다 ② ③ 을 번갈아 보여 준다
- 키를 안 누른 지 약 0.5초가 지나면 ① 로 돌아간다
- 키가 눌릴 때마다 횟수만 1 늘린다. 어떤 키인지는 쓰지도 저장하지도 않는다
- **확인할 것**
  - 메모장 같은 다른 창에서 타자를 쳐도 손이 번갈아 움직인다
  - 빨리 쳐도 프로그램이 멈추거나 느려지지 않는다
  - `pet.py` 안에 키 값을 저장하거나 보내는 곳이 없다
- **커밋**: `week-03: 5단계 타자에 맞춰 손 번갈아 움직이기`

### 6단계 · 잠들기와 깨기
- 10초 동안 키를 안 누르면 ④ 졸기로 바뀐다
- 졸다가 키를 누르면 바로 ② ③ 으로 깬다
- **확인할 것**
  - 10초쯤 가만히 있으면 잠들고, 키 하나에 깬다
  - 끌어서 옮기는 중에도 잠들기·깨기가 잘 된다
- **커밋**: `week-03: 6단계 10초 뒤 잠들기, 키 누르면 깨기`

### 7단계 · 횟수 보여 주기와 저장
- 펫 머리 위에 "오늘 ○번" 을 작게 표시한다 (천 단위에 쉼표)
- `count.json` 에 `{"date": "2026-10-24", "count": 1234}` 처럼 날짜와 숫자만 저장한다. 몇 초마다 한 번, 그리고 끌 때 저장한다
- 켤 때 날짜가 오늘이면 이어서 세고, 다른 날이면 0부터 센다
- **확인할 것**
  - 치는 만큼 숫자가 늘어난다
  - 껐다 켜면 숫자가 이어진다
  - `count.json` 을 열면 날짜와 숫자만 있다
  - `git status` 에 `count.json` 이 보이지 않는다
- **커밋**: `week-03: 7단계 오늘 누른 횟수 표시와 저장`

### 8단계 · pet.exe 로 묶기
- PyInstaller 로 그림 4장을 넣어 `pet.exe` 하나로 묶는다. 실행할 때 검은 터미널 창이 뜨지 않게 한다
- `count.json` 은 exe 옆에 저장되게 한다
- **확인할 것**
  - `dist/pet.exe` 를 두 번 클릭하면 펫이 뜨고, 1~7단계 기능이 모두 된다
  - Windows 보안 경고가 뜨면 무엇이 떴는지 알려 준다
- **커밋**: `week-03: 8단계 pet.exe 로 묶기` (exe 와 묶을 때 생긴 폴더는 올리지 않음)
